::: {#k2-decimal-format .math-exercise-context}

### Desimalt flyttallsformat

Vi bruker et desimalt flyttallsformat med fire signifikante sifre og avrunding
til nærmeste representerbare tall. Regneoperasjoner utføres på de lagrede
verdiene, og resultatet avrundes tilbake til formatet.

Når to nesten like tall subtraheres, kan de ledende sifrene forsvinne. Små
avrundingsfeil i operandene kan da bli store sammenlignet med den lille
differansen. Dette kalles kansellering.

:::

### a) Maskinell differanse

La $x=12.345$ og $y=12.344$.

```{math-exercise}
#| label: exam-k2-8-machine-difference
#| caption: Lagre og subtraher med fire signifikante sifre
#| mode: equivalent
#| partial-credit: true
#| field-labels: lagret x, lagret y, maskinell differanse, eksakt differanse
#| context: k2-decimal-format

Svarformat: Oppgi bare tallverdien i hvert felt. Bruk punktum som
desimalskilletegn, ikke komma.

$$\operatorname{fl}(x)=$$ _[12.35]

$$\operatorname{fl}(y)=$$ _[12.34]

$$\operatorname{fl}(\operatorname{fl}(x)-\operatorname{fl}(y))=$$ _[0.01]

Den eksakte differansen er $x-y=$ _[0.001].
```

::: {#k2-stable-rationalization .math-exercise-context}

### Stabil omskriving

For små $t>0$ er $\sqrt{1+t}$ nær 1. Direkte beregning av
$\sqrt{1+t}-1$ subtraherer derfor to nesten like tall og kan miste mange
signifikante sifre. Ved å multiplisere teller og nevner med den konjugerte
$\sqrt{1+t}+1$ kan subtraksjonen fjernes.

:::

### b–c) Kansellering og rasjonalisering

```{math-exercise}
#| label: exam-k2-8-rationalize
#| caption: Skriv om uttrykket
#| vars: t
#| mode: equivalent
#| reject: sqrt(1+t)-1
#| context: k2-decimal-format, k2-stable-rationalization

Skriv $\sqrt{1+t}-1$ på en matematisk ekvivalent form som unngår subtraksjon
av to nesten like tall.

Svarformat: Bruk variabelen `t` og skriv kvadratroten som `sqrt(...)`. Bruk
vanlige regneoperatorer som `+`, `-`, `*` og `/`. Det opprinnelige uttrykket
godtas ikke.

$$\sqrt{1+t}-1 =$$ __[t/(sqrt(1+t)+1)]
```
