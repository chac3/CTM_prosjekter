# Anvendte matematikkprosjekter ved NTNU

Dette repositoriet brukes til utvikling av anvendte undervisningsmaterialer
for Matematikk 1, Matematikk 2 og Matematikk 3.

## Status

Repositoriet er under faglig og teknisk ombygging.

Eldre Jupyter-notebooker ligger under `legacy/`. Disse kan inneholde:

- uferdig materiale
- utdaterte modeller
- kjente eller ukjente kodefeil
- inkonsistent notasjon
- gamle notebookavhengigheter

Nye materialer utvikles i Quarto-format under `projects/`.

## Tematisk struktur

- 1A: Lineær algebra
- 1B: Kalkulus og førsteordens differensialligninger
- 1C: Andreordens differensialligninger, systemer og egenverdier
- 2: Partielle differensialligninger

## Kjente revisjonstemaer

- SVD og beregning av nullrom
- oppstilling av fagverksmatriser
- numerisk viskositet i Lax-Friedrichs-metoden
- konsekvent notasjon og enheter
- migrering til Quarto og Erasmus-CTM-utvidelser
